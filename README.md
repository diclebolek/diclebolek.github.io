# Dicle Bölek — Özgeçmiş sitesi

GitHub Pages: `https://diclebolek.github.io`

## Yayınlama
1. `diclebolek.github.io` adlı bir depo oluşturun.
2. Bu klasördeki `index.html` ve `assets/` içeriğini deponun köküne koyun.
3. Settings → Pages → Deploy from branch → `main` / root.

CV’ye yapıştırmak için `assets/qr-portfolio.png` dosyasını kullanın (site adresine gider).
